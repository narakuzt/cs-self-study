# CS 自学路线：从零到大学 CS 核心水平

一份面向**零基础、英文较弱的中文自学者**的计算机科学课程规划。它把三个成熟的自学项目——[OSSU Computer Science](https://github.com/ossu/computer-science)、[CS 自学指南 csdiy.wiki](https://csdiy.wiki/)、[teachyourselfcs](https://teachyourselfcs.com/)——的课程、学时、难度和先修数据整理成一条可执行的顺序，并优先选用中文授课或带中文字幕的课程。

对标国内计算机学科统考「408」的四门核心课（数据结构、计算机组成原理、操作系统、计算机网络），同时补上语言、工具、工程三条线。没有截止日期，顺序按依赖关系排，地基不到位不往上盖。

## 设计原则

1. **数据有出处**：学时、难度、先修要求来自 csdiy.wiki 和 OSSU 的原文，页面里逐项标明出处。没有出处的课程，写"无数据"。
2. **中文优先**：每门核心课优先给出中文授课的课程作为主力，国际名课作为进阶或对照，并注明有无中文翻译、字幕。
3. **过关看产出**：每个主题的「过关标准」以课程官方作业为准，少量"自检"题由编者补充并明确标注。
4. **只收核实过的链接**：每页末尾写明核实日期与核实方式。

## 怎么用

1. Fork 本仓库。
2. 按[路线图](路线图.md)的顺序打开各主题页；每页开头是先修要求与规模参考，先看是否满足。
3. 学完后对照页内「过关标准」（每条有编号，如 2.1），通过了在自己的进度文件里打勾。
4. 每次学习按[学习方法](学习方法.md)记录与复习，个人的学习记录放在仓库之外的本地目录。

## 每页的固定结构

先修要求 · 语言 · 规模参考 → 为什么学 → 课程与资源（主力、进阶、对照） → 学习顺序 → 过关标准 → 来源与核实。

## 维护工具

| 脚本 | 作用 |
|---|---|
| `工具/校验链接.py` | 逐个核对所有外部链接：B 站用公开接口核对标题与集数，慕课核对页面标题，YouTube 核对标题，带锚点的链接核对锚点 |
| `工具/校验数据.py` | 核对页面里的星级、学时、周数、每周投入与 csdiy.wiki、OSSU 是否一致 |
| `工具/校验题库.py` | 运行知识层题库里的代码题，核对答案输出 |
| `工具/生成进度追踪.py` | 按各页过关标准的编号生成个人进度文件 |
| `工具/复习.py` | 间隔复习队列：列出到期卡片、闭卷抽问、自动更新档位与日期 |
