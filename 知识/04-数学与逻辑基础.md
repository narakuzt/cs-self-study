### Q04-01 真值表

- 类型：代码题
- 出处：命题逻辑的基本定义（无特定外部链接）
- 问题：`p → q`（p 蕴含 q）在什么情况下为假？

```python
def implies(p, q):
    return (not p) or q

rows = [(p, q, implies(p, q)) for p in (True, False) for q in (True, False)]
for r in rows:
    print(r)
```

- 答案：

```text
(True, True, True)
(True, False, False)
(False, True, True)
(False, False, True)
```

`p → q` 只有在 p 为真、q 为假时才为假，其余三种情况都为真（p 为假时，"如果 p 那么 q"这句话不构成反驳，逻辑上算真，这一点常常和日常语感不一致，需要专门记住）。

### Q04-02 德摩根定律

- 类型：代码题
- 出处：命题逻辑的基本定律
- 问题：`not (p and q)` 和 `(not p) or (not q)` 是否永远相等？

```python
same = all(
    (not (p and q)) == ((not p) or (not q))
    for p in (True, False) for q in (True, False)
)
print(same)
```

- 答案：

```text
True
```

德摩根定律说："否定一个合取（且），等于把两边分别否定后再析取（或）"；反过来，"否定一个析取，等于把两边分别否定后再合取"。这条定律在化简逻辑表达式、写判断条件时经常用到，例如 `not (a and b)` 等价于 `(not a) or (not b)`。

### Q04-03 数学归纳法

- 类型：概念题
- 出处：数学归纳法的标准结构
- 问题：怎样用归纳法证明 `1 + 2 + ... + n = n(n+1)/2` 对所有正整数 n 成立？
- 答案：

分两步。**基础步**：验证 n=1 时成立，左边是 1，右边是 1×2/2=1，相等。**归纳步**：假设 n=k 时成立（归纳假设），即 `1+2+...+k = k(k+1)/2`；要证明 n=k+1 时也成立：左边 `1+2+...+k+(k+1)` 按归纳假设等于 `k(k+1)/2 + (k+1)`，提出公因式 `(k+1)` 得到 `(k+1)(k/2+1) = (k+1)(k+2)/2`，正好是 n=k+1 时公式右边的样子。基础步加归纳步合起来，就证明了公式对所有正整数成立——这好比多米诺骨牌：推倒第一张，且能保证任意一张倒了下一张也会倒，那么所有的都会倒。

### Q04-04 集合运算

### Q04-05 幂集的大小

- 类型：代码题
- 出处：[Python 官方文档：itertools.combinations](https://docs.python.org/zh-cn/3/library/itertools.html#itertools.combinations)
- 问题：一个 4 元素的集合，有多少个子集（包括空集和自身）？

```python
from itertools import combinations

s = {1, 2, 3, 4}
subset_count = sum(1 for k in range(len(s) + 1) for _ in combinations(s, k))
print(subset_count, 2 ** len(s))
```

- 答案：

```text
16 16
```

集合的每个元素都有"选"或"不选"两种可能，n 个元素的所有可能组合数就是 2 的 n 次方，这就是子集的总数（幂集的大小），包括空集（什么都不选）和整个集合本身（全选）。

### Q04-06 笛卡尔积

A, B = [1, 2, 3], ["a", "b"]

### Q04-07 排列

- 类型：代码题
- 出处：[Python 官方文档：math.perm](https://docs.python.org/zh-cn/3/library/math.html#math.perm)、[itertools.permutations](https://docs.python.org/zh-cn/3/library/itertools.html#itertools.permutations)
- 问题：从 5 个人里选 3 个排成一队（考虑顺序），有多少种排法？

```python
import math
from itertools import permutations

people = ["a", "b", "c", "d", "e"]
arrangements = list(permutations(people, 3))
print(len(arrangements), math.perm(5, 3))
```

- 答案：

```text
60 60
```

排列考虑顺序：先选第一个位置有 5 种选择，第二个位置剩 4 种，第三个位置剩 3 种，共 5×4×3=60 种。公式是 `P(n,k) = n!/(n-k)!`。

### Q04-08 组合

- 类型：代码题
- 出处：[Python 官方文档：math.comb](https://docs.python.org/zh-cn/3/library/math.html#math.comb)、[itertools.combinations](https://docs.python.org/zh-cn/3/library/itertools.html#itertools.combinations)
- 问题：从 5 个人里选 3 个组成一组（不考虑顺序），有多少种选法？

```python
import math
from itertools import combinations

people = ["a", "b", "c", "d", "e"]
groups = list(combinations(people, 3))
print(len(groups), math.comb(5, 3))
```

- 答案：

```text
10 10
```

组合不考虑顺序：每一组 3 人的排列有 3!=6 种排法，都对应同一个组合，所以组合数是排列数除以 3!，即 60/6=10。公式是 `C(n,k) = n!/(k!(n-k)!)`。

### Q04-09 鸽笼原理

- 类型：代码题
- 出处：鸽笼原理的标准表述
- 问题：把 13 个数分别放进 12 个"余数为 0 到 11"的抽屉（按除以 12 的余数分类），一定会有两个数同余吗？

```python
nums = list(range(100, 113))  # 任取 13 个数
buckets = {}
for n in nums:
    buckets.setdefault(n % 12, []).append(n)
has_collision = any(len(v) >= 2 for v in buckets.values())
print(len(nums), len(buckets), has_collision)
```

- 答案：

```text
13 12 True
```

鸽笼原理：把 n+1 个物体放进 n 个抽屉，必然有一个抽屉里至少放了 2 个物体，不需要具体知道是哪个抽屉。这里 13 个数、12 个可能的余数，一定有两个数除以 12 的余数相同（同余）。这个原理本身很直观，但能推出很多不直观的结论，比如"任意 367 个人里一定有两人生日相同"。

### Q04-10 容斥原理

- 类型：代码题
- 出处：容斥原理的标准公式
- 问题：1 到 30 里，能被 2 整除或能被 3 整除的数有多少个？

```python
A = {n for n in range(1, 31) if n % 2 == 0}
B = {n for n in range(1, 31) if n % 3 == 0}
union_count = len(A | B)
formula = len(A) + len(B) - len(A & B)
print(union_count, formula)
```

- 答案：

```text
20 20
```

直接数并集容易漏算或重复算，容斥原理给出公式：`|A∪B| = |A| + |B| - |A∩B|`，因为 A 和 B 各自的计数里，两者都满足的部分（既能被 2 整除又能被 3 整除，即被 6 整除）被数了两次，要减去一次。这里 15 个偶数加 10 个 3 的倍数，减去 5 个 6 的倍数，得到 20。

### Q04-11 握手定理

- 类型：代码题
- 出处：图论的握手定理（度数和公式）
- 问题：一个无向图里，所有顶点的度数加起来，和边数有什么关系？

```python
edges = [(1, 2), (2, 3), (3, 1), (3, 4)]
degree = {}
for a, b in edges:
    degree[a] = degree.get(a, 0) + 1
    degree[b] = degree.get(b, 0) + 1
print(sum(degree.values()), 2 * len(edges))
```

- 答案：

```text
8 8
```

每条边连接两个顶点，给两边的度数各贡献 1，所以所有顶点的度数之和永远等于边数的 2 倍（不管图长什么样）。这个定理还能推出一个推论：一个无向图里，度数为奇数的顶点个数一定是偶数个。

### Q04-12 邻接矩阵与邻接表

- 类型：代码题
- 出处：图的两种常见表示法
- 问题：同一个图，邻接矩阵和邻接表分别怎么表示？

```python
edges = [(0, 1), (0, 2), (1, 2)]
n = 3
matrix = [[0] * n for _ in range(n)]
adj = {i: [] for i in range(n)}
for a, b in edges:
    matrix[a][b] = matrix[b][a] = 1
    adj[a].append(b)
    adj[b].append(a)
print(matrix)
print({k: sorted(v) for k, v in adj.items()})
```

- 答案：

```text
[[0, 1, 1], [1, 0, 1], [1, 1, 0]]
{0: [1, 2], 1: [0, 2], 2: [0, 1]}
```

邻接矩阵用一个 n×n 的表格记录任意两点是否相连，查询"i 和 j 是否相邻"很快（直接查表），但即使图很稀疏也要占 n² 的空间。邻接表对每个顶点只记录它实际连接的邻居，稀疏图时省空间，但查询"i 和 j 是否相邻"要遍历 i 的邻居列表。数据结构与算法阶段会用到这两种表示法实现图的遍历。

### Q04-13 图的连通性

- 类型：代码题
- 出处：图的连通性定义，用广度优先搜索判断
- 问题：怎样判断一个无向图是不是连通的（任意两点间都有路径）？

```python
def is_connected(n, edges):
    adj = {i: [] for i in range(n)}
    for a, b in edges:
        adj[a].append(b)
        adj[b].append(a)
    visited = {0}
    queue = [0]
    while queue:
        cur = queue.pop()
        for nxt in adj[cur]:
            if nxt not in visited:
                visited.add(nxt)
                queue.append(nxt)
    return len(visited) == n

print(is_connected(4, [(0, 1), (1, 2), (2, 3)]))
print(is_connected(4, [(0, 1), (2, 3)]))
```

- 答案：

```text
True
False
```

从任意一个顶点出发做一次遍历（这里用广度优先搜索），如果能访问到所有顶点，图就是连通的；如果遍历完还有顶点没访问到，说明图分成了几个互不连通的部分。这是「5. 数据结构与算法」里图遍历算法的一个直接应用。

### Q04-14 等可能情形下的概率

- 类型：代码题
- 出处：古典概率的定义
- 问题：掷两枚骰子，点数之和为 7 的概率是多少？

```python
from fractions import Fraction

outcomes = [(a, b) for a in range(1, 7) for b in range(1, 7)]
favorable = [o for o in outcomes if sum(o) == 7]
print(len(favorable), len(outcomes), Fraction(len(favorable), len(outcomes)))
```

- 答案：

```text
6 36 1/6
```

两枚骰子一共有 6×6=36 种等可能的结果。和为 7 的组合有 (1,6)(2,5)(3,4)(4,3)(5,2)(6,1) 共 6 种，概率是"有利结果数除以总结果数"，即 6/36 化简为 1/6。

### Q04-15 期望

- 类型：代码题
- 出处：离散型随机变量期望的定义
- 问题：掷一枚骰子，点数的期望是多少？

```python
from fractions import Fraction

values = range(1, 7)
p = Fraction(1, 6)
expectation = sum(v * p for v in values)
print(expectation, float(expectation))
```

- 答案：

```text
7/2 3.5
```

期望是每种结果乘以它出现的概率，再全部加起来，代表"平均而言会得到多少"。这里六个面出现概率相同，期望是 (1+2+3+4+5+6)/6=3.5，虽然骰子永远不会真的掷出 3.5 点。

### Q04-16 条件概率

- 类型：代码题
- 出处：条件概率的定义 `P(A|B) = P(A∩B)/P(B)`
- 问题：掷两枚骰子，已知点数之和是偶数，两个点数都是 3 的概率是多少？

```python
from fractions import Fraction

outcomes = [(a, b) for a in range(1, 7) for b in range(1, 7)]
B = [o for o in outcomes if sum(o) % 2 == 0]         # 和为偶数
A_and_B = [o for o in B if o == (3, 3)]
print(Fraction(len(A_and_B), len(outcomes)) / Fraction(len(B), len(outcomes)))
print(Fraction(len(A_and_B), len(B)))
```

- 答案：

```text
1/18
1/18
```

条件概率 `P(A|B)` 是"在已知 B 发生的前提下，A 发生的概率"，相当于把样本空间缩小到只有 B 发生的那些结果，再看 A 占其中的比例。这里"和为偶数"缩小了样本空间到 18 种结果，`(3,3)` 是其中 1 种，所以条件概率是 1/18。

### Q04-17 矩阵乘法

- 类型：代码题
- 出处：矩阵乘法"行点乘列"的定义
- 问题：两个 2×2 矩阵相乘，每个元素是怎么算出来的？

```python
def matmul(A, B):
    n, m, p = len(A), len(B), len(B[0])
    return [[sum(A[i][k] * B[k][j] for k in range(m)) for j in range(p)] for i in range(n)]

A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]
print(matmul(A, B))
```

- 答案：

```text
[[19, 22], [43, 50]]
```

结果矩阵第 i 行第 j 列的元素，是 A 的第 i 行和 B 的第 j 列对应位置相乘再求和（"行点乘列"）。比如结果的 [0][0] 是 `1×5 + 2×7 = 19`。矩阵乘法不满足交换律，`A×B` 一般不等于 `B×A`。

### Q04-18 用极限定义数值逼近导数

- 类型：代码题
- 出处：导数的极限定义 `f'(x) = lim(h→0) (f(x+h)-f(x))/h`
- 问题：函数 `f(x)=x²` 在 `x=3` 处的导数，怎样用很小的 h 数值逼近？理论值是多少？

```python
def f(x):
    return x ** 2

x, h = 3, 1e-6
numeric = (f(x + h) - f(x)) / h
print(round(numeric, 4), 2 * x)
```

- 答案：

```text
6.0 6
```

导数描述函数在某一点的瞬时变化率，定义为"当 h 趋近于 0 时，函数值变化量除以 h"的极限。取一个很小的 h（比如 1e-6）直接代入公式计算，得到的近似值会非常接近理论值。`x²` 的导数公式是 `2x`，在 x=3 处理论值是 6，和数值逼近的结果吻合。
