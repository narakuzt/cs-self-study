# 1. 计算机整体直觉

| 项目 | 内容 |
|---|---|
| 先修要求 | 无 |
| 语言 | 无 |
| 规模参考 | csdiy.wiki：Crash Course 系列约 8 小时；《CODE》无数据 |

## 为什么学

csdiy.wiki 在学习规划开头就向小白强烈推荐这个系列：它以 Computers are not magic! 为口号，讲计算机的历史、如何运作、各重要模块和重要思想，让你对计算机科学有全貌性的感知，再去面对后面浩如烟海的细节。

## 课程与资源

> 说明：星级、学时、先修要求来自 csdiy.wiki 或 OSSU 的原文；"主力、进阶、备选"的划分、学习顺序是编者建议。

### 主线（中文友好）

1. [Crash Course: Computer Science（计算机科学速成课）](https://www.bilibili.com/video/BV1EW411u7th)：csdiy.wiki 推荐的 B 站版本，约 8 小时；该合集为"CrashCourse 字幕组"上传，标题标注"40 集全/精校"。
   - 原版 YouTube：[播放列表](https://www.youtube.com/playlist?list=PL8dPuuaLjXtNlUrzyH5r6jN9ulIgZBpdo)。
2. 《CODE：隐匿在计算机软硬件背后的语言》（Charles Petzold，书）：不需要任何基础。选择依据：编者选定；无课程数据。

### 延伸

- [Nand2Tetris](https://www.nand2tetris.org/course)：从与非门造出计算机，放在 [6. 计算机组成原理](06-计算机组成原理.md) 阶段做。

## 学习顺序（编者建议）

1. 先看速成课，看到"CPU 如何执行指令"这一段时，同步读《CODE》对应章节。
2. 看完后，用自己的话写一段总结，不看资料。

## 过关标准

- [ ] 自检：不超过一页纸，讲清楚"一段 Python 代码从敲下回车到屏幕出现结果，中间发生了什么"（源码、解释器、机器指令、CPU、内存、操作系统、输出）
- [ ] 自检：画出与门、或门、非门的真值表，并说明半加器如何用它们组成
- [ ] 自检：说明二进制、十六进制、ASCII 与 Unicode 各自是什么、为什么需要它们
