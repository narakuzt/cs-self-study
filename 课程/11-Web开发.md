## 为什么学

Web 是最容易做出"别人能用"的东西的平台，也是把前面学的语言、网络、数据库串起来的实战场。

## 学习顺序（编者建议）

1. MDN：HTML → CSS → JavaScript，每段做一个小页面。
2. 补上 [10. 数据库](10-数据库.md) 与 [9. 版本管理](09-版本管理.md) 后，学 Full Stack Open。
3. 做一个"前端页面加后端接口加数据库"的完整应用。

## 过关标准

- [ ] Full Stack Open：完成课程各部分的练习
- [ ] 自检：手写一个响应式页面（HTML+CSS），手机与电脑都可读
- [ ] 自检：用浏览器开发者工具看到一次请求的请求头、响应头与状态码，并解释
- [ ] 自检：解释 GET 与 POST 的区别，Cookie 与 Session 各解决什么问题
