# 6. 计算机组成原理

| 项目 | 内容 |
|---|---|
| 先修要求 | [1. 计算机整体直觉](01-计算机整体直觉.md)；进阶课程需 C 语言（见 [3. C 与 C++ 基础](03-C与C++基础.md)） |
| 语言 | 主力课程不要求；进阶课程用 C、汇编 |
| 规模参考 | teachyourselfcs：每门核心课 100-200 小时 |

## 默认路径

按下面几步走，其余资源是可选的（编者建议）。

0. 做[知识层](../知识/06-计算机组成原理.md)的概念清单与自测题库，衔接主题 1 的二进制基础。
1. 做 Nand2Tetris（nand2tetris.org 免费版）第一部分，从与非门造出计算机。
2. 学哈尔滨工业大学《计算机组成原理》。
3. CSAPP 是进阶，建议学完 3 与 5 后再上；完成「过关标准」。

## 为什么学

teachyourselfcs：没有对计算机如何工作的心智模型，抽象一旦泄漏就会束手无策。这一门把「整体直觉」拆到硬件：数据怎么表示、指令怎么执行、缓存为何让程序快慢差几十倍。

## 课程

编者建议的顺序：Nand2Tetris → 哈工大《计算机组成原理》→ CSAPP。

> 说明：星级、学时、先修要求来自 csdiy.wiki 或 OSSU 的原文；"主力、进阶、备选"的划分与推荐顺序是编者建议。


### 第一步：Nand2Tetris（从与非门造一台计算机）

| 项目 | csdiy.wiki 数据 | OSSU 数据 |
|---|---|---|
| 先修要求 | 无 | 第一部分：类 C 语言；第二部分：需先学第一部分 |
| 编程语言 | 任选一门 | 同左 |
| 难度 / 时长 | 3 星，40 小时 | 第一部分 6 周、每周 7-13 小时；第二部分 6 周、每周 12-18 小时 |

- [课程网站](https://www.nand2tetris.org/course)；csdiy.wiki 给出 Coursera 的[第一部分](https://www.coursera.org/learn/build-a-computer/home/week/1)与[第二部分](https://www.coursera.org/learn/nand2tetris2/home/welcome)；Coursera 自 2025 年 7 月起，大部分课程不再提供免费旁听（OSSU FAQ），免费版以课程网站为准。
- 作业：csdiy.wiki 记为 10 个 Project，具体划分以课程网站为准。
- 先修：csdiy.wiki 标注无；OSSU 标注第一部分需要类 C 的编程语言基础。编者建议把它作为本主题的入口。

### 第二步（中文主力）：哈尔滨工业大学《计算机组成原理》（唐朔飞）

- [上](https://www.icourse163.org/course/hit-309001)、[下](https://www.icourse163.org/course/hit-1001527001)（中国大学 MOOC）
- 中文授课。选择依据：国内考研统考 408 对应的中文课，编者选定，备选为南京大学袁春风《计算机组成与系统结构》。csdiy.wiki 与 OSSU 均未收录这门课，因此没有它们的难度和学时数据。

### 第三步（进阶）：CSAPP / CMU 15-213

| 项目 | csdiy.wiki 数据 |
|---|---|
| 先修要求 | CS61A、CS61B |
| 编程语言 | C |
| 难度 | 5 星 |
| 预计学时 | 150 小时 |

- csdiy.wiki 评价：内容庞杂，Project 巨难；覆盖汇编、体系结构、操作系统、编译链接、并行、网络。
- 提醒（编者建议）：csdiy.wiki 给出的先修（CS61A、CS61B）对零基础偏重，建议完成 [3. C 与 C++ 基础](03-C与C++基础.md) 与 [5. 数据结构与算法](05-数据结构与算法.md) 后再学。
- [课程网站（Wayback 快照）](https://web.archive.org/web/20260801124538/https://csapp.cs.cmu.edu/)、[课程视频（B 站，2015 年版，26 集）](https://www.bilibili.com/video/BV1iW411d7hd)、[B 站中文讲解（九曲阑干，链接为系列第 1 讲）](https://www.bilibili.com/video/BV1cD4y1D7uR)
- 教材：Computer Systems: A Programmer's Perspective（第 3 版）；csdiy.wiki 另推荐《程序员的自我修养》。
- 作业：[11 个 Lab（Wayback 快照）](https://web.archive.org/web/20260918194836/https://csapp.cs.cmu.edu/3e/labs.html)。teachyourselfcs 建议读第 1-6 章。

## 过关标准

- **6.1** Nand2Tetris：完成第一部分的全部 Project（编号以课程网站为准），通过官方测试
- **6.2** 哈工大计组：完成课程页要求的全部作业（作业形式以课程页为准）
- **6.3** CSAPP（进阶）：完成官方 11 个 Lab 中的大部分，目标是全部完成——CSAPP 的实验分数通常是这门课的主要构成，真实选课的学生正常都要做完，只做 Data Lab、Bomb Lab、Cache Lab 这三个经典 Lab 只是最低限度，不算真正学完这门课
- **6.4** 闭卷做完[知识层](../知识/06-计算机组成原理.md)的 16 道自测题，做错的加入复习队列，一周后复测
