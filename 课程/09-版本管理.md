## 默认路径

按下面几步走，其余资源是可选的（编者建议）。

1. 读 Pro Git（中文）第 1-5 章，同时用 Learn Git Branching 练习。
2. 用 GitHub 官方入门教程建立并推送一个仓库，练一次 Pull Request。
3. 完成「过关标准」。

## 为什么学

csdiy.wiki：Git 是分布式版本控制工具，设计优雅，但初学者常因不理解其内部逻辑而误用命令、把代码"控制没了"。它是每个学 CS 的人必须掌握的工具之一。编者建议：在第一个项目开始时就学，不要等到最后。

## 学习路线（引自 csdiy.wiki 的 Git 页）

> 说明：星级、学时、先修要求来自 csdiy.wiki 或 OSSU 的原文；"主力、进阶、备选"的划分、学习顺序是编者建议。

csdiy.wiki 指出：Git 的内部逻辑不能熟能生巧，需要花时间去理解，不建议在一知半解时贸然使用。推荐路线如下（第 1 步链接 2026 版讲义、第 2 步链接中文版 Pro Git；csdiy.wiki 原文分别链接 2020 版讲义与英文版）：

1. 阅读 [Missing Semester：版本控制](https://missing.csail.mit.edu/2026/version-control/)；中文视频可看[尚硅谷 Git 教程（B 站）](https://www.bilibili.com/video/BV1vy4y1s7k6)。
2. 阅读 [Pro Git](https://git-scm.com/book/zh/v2)（中文版）的第 1-5 章。
3. 用 [Learn Git Branching](https://learngitbranching.js.org/?locale=zh_CN) 交互式练习。
4. 做[知识层](../知识/09-版本管理.md)的概念清单与自测题库，在实践中巩固命令；读一篇[如何写好 Commit Message](https://chris.beams.io/posts/git-commit/)。
5. 进阶：[Write yourself a Git](https://wyag.thb.lt/)，自己实现一个 Git。

## GitHub

- [GitHub 官方入门教程（中文）](https://docs.github.com/cn/get-started)：建立远程仓库、克隆他人代码。
- [HelloGitHub](https://hellogithub.com/)：每期收录有趣的开源项目。
- [GitHub Skills](https://skills.github.com/)：官方交互式小课程，练习 Pull Request 流程。

## 过关标准

- **9.1** 读完 Pro Git 第 1-5 章（csdiy.wiki 的建议）
- **9.2** 自检：完成 Learn Git Branching 的各关卡
- **9.3** 自检：故意制造一次合并冲突并解决；用 `reset`、`revert`、`restore` 各回退一次，说明区别
- **9.4** 自检：解释 Git 中 blob、tree、commit 分别是什么
- **9.5** 自检：在 GitHub 上提交一个 Pull Request 并合并
- **9.6** 闭卷做完[知识层](../知识/09-版本管理.md)的 30 道自测题，做错的加入复习队列，一周后复测
