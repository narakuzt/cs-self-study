# 8. 计算机网络

| 项目 | 内容 |
|---|---|
| 先修要求 | [2. Python 基础](02-Python基础.md)；建议先学完 [7. 操作系统](07-操作系统.md) 的进程与文件部分 |
| 语言 | 主力课程无编程作业；进阶课程用 C++ |
| 规模参考 | teachyourselfcs：每门核心课 100-200 小时 |

## 默认路径

按下面几步走，其余资源是可选的（编者建议）。

1. 读教材《计算机网络：自顶向下方法》对应章节，再看中国科学技术大学的课程视频。
2. 做 Kurose 官网的 Wireshark 实验（HTTP、DNS、TCP）。
3. CS144 是进阶；完成「过关标准」——做[知识层](../知识/08-计算机网络.md)的自测题库，用 Python socket 在本机实际收发数据，直接体会 TCP、UDP、HTTP 的行为。

## 为什么学

teachyourselfcs：理解互联网如何工作，才能理解它的可能性。浏览器怎么打开网页、消息怎么送到对方、为什么会掉线，服务端开发、分布式系统和安全都建立在这里。

## 过关标准

- **8.1** 中科大课程：看完全部课程视频，并在看每章视频前读完教材对应章节（csdiy.wiki 的强烈建议）
- **8.2** Kurose 官网 [Wireshark 实验](https://gaia.cs.umass.edu/kurose_ross/wireshark.php)：官网列出 Getting Started 加 12 个协议实验（HTTP、DNS、TCP、UDP、IP、NAT、DHCP、ICMP、以太网与 ARP、802.11 WiFi、5G、TLS），全部完成——这些实验是配合课程内容设计的，不是选做的附加题，只做 3 个远不到这门课该有的深度
- **8.3** 自检：用 Wireshark 抓一次访问网页，标出 DNS 查询、TCP 三次握手、HTTP 请求与响应
- **8.4** （进阶）CS144：完成课程网站列出的全部实验（实验内容以官网为准）
- **8.5** 闭卷做完[知识层](../知识/08-计算机网络.md)的 16 道自测题，做错的加入复习队列，一周后复测
