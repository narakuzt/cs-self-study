# 10. 数据库

| 项目 | 内容 |
|---|---|
| 先修要求 | 三门中文数据库课的课程页均写明：数据结构、操作系统，另有编程与离散数学；OSSU 对 Stanford 三门课写"core programming"（指 OSSU 的编程课系列，较重）；只学 SQL 可提前，无硬性先修（编者建议） |
| 语言 | SQL；系统课程用 C++ 或 Java |
| 规模参考 | 华中科技大学：视频约 700 分钟；OSSU：Stanford 三门数据库课各 2 周、每周 10 小时；csdiy.wiki：15-445 约 100 小时 |

## 为什么学

teachyourselfcs：数据驱动着绝大多数有价值的程序，应当理解数据库系统的内部。会用 SQL 是日常技能，理解存储、索引、事务、恢复则让你判断"为什么这个查询慢""数据为什么会丢"。

## 学习顺序（编者建议）

1. 想先会用 SQL：做 SQL 练习，再在 PostgreSQL 上建一个自己的库。这一步不需要上述先修。
2. 系统学数据库：三门中文课都要求学过数据结构和操作系统，所以放在 [5. 数据结构与算法](05-数据结构与算法.md) 和 [7. 操作系统](07-操作系统.md) 之后，学中国人民大学基础篇。
3. 想深入内部：学 15-445；按 csdiy.wiki 的先修，需要先学 C++、数据结构与算法、CSAPP。

## 过关标准

- [ ] 中国人民大学基础篇：完成课程页要求的作业与实验（形式以课程页为准）
- [ ] 自检：建 4 张以上含外键的表，写 10 条查询，覆盖多表连接、聚合分组、子查询
- [ ] 自检：用 `EXPLAIN` 看执行计划，加索引后对比前后
- [ ] 自检：用参数化查询从 Python 连接数据库，并说明为什么要防 SQL 注入
- [ ] （深入）15-445：完成官网列出的 Project（以官网为准）
