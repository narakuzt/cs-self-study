## 默认路径

按下面几步走，其余资源是可选的（编者建议）。

1. 先学浙江大学《程序设计入门——C语言》，重点是指针、数组与字符串、结构体、动态内存。
2. 用 C 手写一个链表，再学 C++：清华中文课程或 LearnCpp，同步对照《C++ Primer Plus》。
3. 学 CS106L，完成「过关标准」。

## 为什么学

编者观点：本项目把 C 与 C++ 作为第二、第三门语言，先 C 后 C++。原因有两个：一是后面的系统类课程需要它们，按 csdiy.wiki 的字段，CSAPP、MIT 6.1810、哈工大操作系统的编程语言是 C（后两者还有汇编），CMU 15-445 与 Stanford CS144 是 C++；二是 C 与 C++ 会让你直面指针、内存布局与手动管理资源，这些在 Python 里被隐藏。

## 学习顺序（编者建议）

1. C 语言：按浙大课程的顺序学完主线，重点放在指针、数组与字符串、结构体、动态内存。
2. 用 C 手写一个链表（见过关标准），再学 C++。
3. C++：中文课程或 LearnCpp 按序学，同时对照《C++ Primer Plus》；每章末的练习必做。
4. 然后学 CS106L 的标准库与现代写法；想用 C++ 学数据结构时，再接 CS106B。

## 过关标准

- **3.1** 浙大《程序设计入门——C语言》：完成课程页要求的全部作业（作业形式以课程页为准）
- **3.2** 自检：用 C 手写单向链表（插入、删除、反转、释放），并用 `valgrind` 确认没有内存泄漏
- **3.3** 自检：解释指针、数组名与字符串在 C 里的关系，并说明 `sizeof` 对数组与指针的结果为何不同
- **3.4** CS106L：完成官方两个作业
- **3.5** 自检：用 C++ 实现同一个链表，并用 `-fsanitize=address` 确认无内存泄漏
- **3.6** 自检：用 `gdb` 设断点、单步、查看变量，定位一个人为制造的段错误
