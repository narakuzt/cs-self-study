# 13. 其他编程语言

| 项目 | 内容 |
|---|---|
| 先修要求 | [2. Python 基础](02-Python基础.md)、[3. C++ 基础](03-C++基础.md)（编者建议） |
| 语言 | Rust、Java、函数式语言等，按兴趣选 |
| 规模参考 | csdiy.wiki：Rust CS110L 30 小时，MIT 6.092 Java 不到 15 小时，OCaml CS3110 40 小时 |

## 为什么学

teachyourselfcs：理解语言与编译器，能写出更好的代码，也能更快学会新语言。本主题**视兴趣选学，不是必修**，优先级低于 C++。

## 课程与资源

> 说明：星级、学时、先修要求来自 csdiy.wiki 或 OSSU 的原文；"主力、进阶、备选"的划分、学习顺序是编者建议。

### Rust

- 主力：[《Rust 程序设计语言》（官方中文版）](https://kaisery.github.io/trpl-zh-cn/)。选择依据：编者选定；无课程数据。
- [Stanford CS110L：Safety in Systems Programming](https://reberhardt.com/cs110l/spring-2020/)：csdiy.wiki：3 星，30 小时；先修：最好有编程背景并对系统有初步认识；6 个 Lab 和 2 个 Project；[视频](https://youtu.be/j7AQrtLevUE)。

### Java

- 主力书：《Head First Java》、《Java 核心技术》卷 I（编者选定；无课程数据）。
- [MIT 6.092：Introduction to Programming in Java](https://ocw.mit.edu/courses/6-092-introduction-to-programming-in-java-january-iap-2010/pages/syllabus/)：csdiy.wiki：2 星，少于 15 小时，先修无。

### 函数式

- [Cornell CS3110：OCaml Programming](https://cs3110.github.io/textbook)：csdiy.wiki：3 星，40 小时；先修：了解一门命令式语言；[课程视频](https://www.youtube.com/playlist?list=PLre5AT9JnKShBOPeuiD9b-I4XROIJhkIU)，csdiy.wiki 称开英文字幕理解起来毫不费力。

## 学习顺序（编者建议）

1. 选定一门语言，读官方或课程教材，做全部练习。
2. 用新语言重写 [5. 数据结构与算法](05-数据结构与算法.md) 里的几个数据结构，感受差异。
3. 想深入时，读 Crafting Interpreters 或选一门编译原理课。

## 过关标准

- [ ] 选定语言的课程作业全部完成（如 CS110L 的 6 个 Lab 与 2 个 Project）
- [ ] 自检：说明新语言与 Python、C++ 在内存管理、类型系统、错误处理上的三处差异
