## 为什么学

编者观点：本项目把 C++ 作为第二门语言。原因有两个：一是后面的系统类课程需要 C 或 C++，按 csdiy.wiki 的字段，CSAPP、MIT 6.1810、哈工大操作系统的编程语言是 C（后两者还有汇编），CMU 15-445 与 Stanford CS144 是 C++；二是 C++ 会让你直面指针、内存布局与手动管理资源，这些在 Python 里被隐藏。

## 学习顺序（编者建议）

1. LearnCpp 基础章节按序学，每章末测验必做，同时对照《C++ Primer Plus》。
2. 学到指针与动态内存时放慢，手写数据结构练习。
3. 然后学 CS106L 的标准库与现代写法。
4. 想用 C++ 学数据结构时，再接 CS106B。

## 过关标准

- [ ] CS106L：完成官方两个作业
- [ ] 自检：用指针手写单向链表（插入、删除、反转、释放），并用 `-fsanitize=address` 确认无内存泄漏
- [ ] 自检：用 `gdb` 设断点、单步、查看变量，定位一个人为制造的段错误
