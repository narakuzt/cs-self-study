## 默认路径

按下面几步走，其余资源是可选的（编者建议）。

1. 学哈尔滨工业大学《操作系统》（李治军），做课程实验。
2. 用 OSTEP 与 ostep-homework 对照巩固。
3. MIT 6.1810 是进阶；完成「过关标准」，再回头学 Python 的多进程、线程、GIL——做[知识层](../知识/07-操作系统.md)的自测题库，这些题目直接用 Python 演示 fork、管道、信号、线程竞态和 GIL，正好衔接。

## 为什么学

teachyourselfcs：你写的代码运行在操作系统上，要理解二者如何交互。进程、线程、内存、文件、锁、系统调用，是并发 bug 和性能问题的根源。

这一门也是回头理解 Python 多进程、线程、GIL 的前提：那些概念在没有操作系统背景时很难真正理解，学完这里再回头看会清楚得多。

### 中文主力：哈尔滨工业大学《操作系统》（李治军）

| 项目 | csdiy.wiki 数据 |
|---|---|
| 先修要求 | C 语言 |
| 编程语言 | C、汇编 |
| 难度 | 4 星 |
| 预计学时 | 100 小时以上 |

- csdiy.wiki 评价：中文互联网上知名度很高的操作系统课；从"什么是操作系统"讲起，循循善诱。基于 Linux 0.11 源码，共 8 个小实验、4 个大实验；强调必须做实验。
- 也提醒：Linux 0.11 是早期工业代码，实验里会遇到晦涩的原生代码，对理解操作系统帮助有限。
- [课程（中国大学 MOOC）](https://www.icourse163.org/course/HIT-1002531008)、[视频（B 站）](https://www.bilibili.com/video/BV19r4y1b7Aw/?p=1)、[实验（蓝桥云课）](https://www.lanqiao.cn/courses/115)
- 教材：《Linux 内核完全注释》、《操作系统原理、实现与实践》。

### 国际对照：OSTEP（Operating Systems: Three Easy Pieces）

- [免费在线教材](https://pages.cs.wisc.edu/~remzi/OSTEP/)；teachyourselfcs 主推，OSSU 也收录。
- OSSU 数据：10-12 周，每周 6-10 小时；先修 Nand to Tetris 第二部分。
- 配套：[ostep-homework](https://github.com/remzi-arpacidusseau/ostep-homework)、[ostep-projects](https://github.com/remzi-arpacidusseau/ostep-projects)。

## 过关标准

- **7.1** 哈工大操作系统：完成 8 个小实验（csdiy.wiki 数据）
- **7.2** （进阶）哈工大操作系统：完成 4 个大实验——这门课本身强调"不做实验学不好操作系统"，4 个都做完是正常选课学生的工作量，不是可以挑着做的可选项
- **7.3** OSTEP：完成 ostep-homework 仓库中与已学章节对应的习题（以仓库说明为准）
- **7.4** （进阶）xv6：完成 MIT 6.1810 官网列出的全部 lab（通常 9 个）——这是真实选课学生的正常工作量；Utilities、System calls、Page tables 这三个是入门，只做这三个不算学完这门课
- **7.5** 自检：不看资料说明进程与线程的区别、`fork()` 后父子进程的地址空间、什么是死锁
- **7.6** 闭卷做完[知识层](../知识/07-操作系统.md)的 20 道自测题，做错的加入复习队列，一周后复测
